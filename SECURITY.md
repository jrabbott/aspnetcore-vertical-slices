# Security policy

## Supported versions

This repository is a **sample / learning** ASP.NET Core weather app. Only the latest commit on `main` is maintained.

## Reporting a vulnerability

Please **do not** open a public issue for security vulnerabilities.

Use [GitHub Private Vulnerability Reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability) for this repository (Security tab → Report a vulnerability).

If private reporting is not yet enabled on the repository, contact the owner via GitHub ([@jrabbott](https://github.com/jrabbott)) instead.

## Scope note

Local demos use the free [Open-Meteo](https://open-meteo.com/) API and do not require API keys for typical non-commercial use. Prefer reporting issues that affect the sample’s own code, dependencies, or CI configuration.
