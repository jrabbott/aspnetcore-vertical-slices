# Diátaxis quadrant guide (this repo)

| Quadrant | Folder | Reader need | Example in this repo |
|---|---|---|---|
| Tutorial | `docs/tutorials/` | Learn by doing | `run-the-weather-app.md` |
| How-to | `docs/how-to/` | Achieve a goal | `add-a-feature-slice.md` |
| Reference | `docs/reference/` | Look up facts | `routes.md`, `testing.md` |
| Explanation | `docs/explanation/` | Understand why | `vertical-slice-architecture.md` |

## Quick tests

- “Teach me to run the app” → tutorial
- “How do I add a slice / swap Open-Meteo?” → how-to
- “What are the routes / build flags?” → reference
- “Why VSA / why root `_ViewImports`?” → explanation

After adding a page, list it in `docs/README.md` (and the root README Diátaxis table when it is a primary entry point).
